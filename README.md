# Tampa Bay Visitors Bureau

A student-designed visitor guide to Tampa Bay, Florida — built for the FBLA 2026-2027 Exploring Website Design event ("Explore Your Area: Create a Visitors Bureau Website").

## View the site

Open `index.html` in any browser, or publish it with GitHub Pages: Settings → Pages → Deploy from a branch → `main` (root). The site will be live at `https://<username>.github.io/<repository>/`.

## What's inside

A single self-contained page (`index.html`) with everything built in:

- Attractions, beaches, museums, Ybor City, sports, and entertainment
- Food and drink, shopping, and where to stay
- Events calendar, itineraries, and day trips within 150 miles
- Visitor guide: best time to visit, getting around, safety, accessibility
- Hospitals and important phone numbers in the contacts section
- Interactive map, favorites shortlist, and a downloadable packing checklist

Original student entry for the 2026-27 "Explore Your Area" topic. Photo sources are credited in the site footer.
